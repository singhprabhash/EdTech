# Locally hosted fonts

Manrope Variable and Newsreader Variable, Latin normal WOFF2, from
`@fontsource-variable/manrope@5.3.0` and
`@fontsource-variable/newsreader@5.3.0` npm distribution archives.
No runtime font service or dependency was added. Corresponding SIL Open Font
License texts are included beside the font files.

Sources: https://fontsource.org/fonts/manrope and
https://fontsource.org/fonts/newsreader . These fonts cover the initial English
interface. Add the appropriate licensed subsets before rendering other scripts.
